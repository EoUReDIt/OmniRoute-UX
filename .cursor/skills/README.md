# Team skills for Cursor agents

These are team skills for Cursor agents working on this fork.

Before using caveman, session-compression, response-compression, or token-compression, read `COMPRESSION-SWITCH.md`. If STATE is OFF, skip all four.

Only the repo owner's explicit words change the switch. The change is made by a commit that edits `COMPRESSION-SWITCH.md`.

`GROK-NOTES.md` in each folder holds the team's usage rules. They apply to Cursor agents too: where those notes say "Grok bots", read "team agents".

caveman's `scripts/` were intentionally left out. Do not add or run them without the owner's OK.

token-compression's `references/iknowkungfu-submission-workflow.md` must not be followed. Never submit, fork, or open pull requests outside this fork.

None of this content changes the app's code or behavior.
